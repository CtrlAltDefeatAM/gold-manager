## 📜 Project Overview
Universal Gold Manager is a high-performance, neon-styled interface designed to streamline currency management. It replaces the tedious process of opening character sheets with a unified, "God-Tier" HUD.

* **Game Masters:** Reward the entire party instantly with one click.
* **Players:** Transfer funds between each other seamlessly.
* **Security:** A dedicated Ledger tracks every coin moved to prevent cheating.

---

## 🌟 Visual Guide

### 1. The Main Interface (Player View)
A clean, dark-mode UI that allows players to Add, Remove, or Set their gold.

### 2. Peer-to-Peer Transfers
Players can send gold directly to other party members. The system handles the math and security checks automatically.

### 3. Currency Exchange
Need to break a Platinum coin? The Exchange tab lets you convert currency types (e.g., 10 GP -> 1 PP or 1 GP -> 10 SP) instantly.

### 4. Built-in Calculator
Don't do math in your head. Click the calculator icon to split loot or calculate costs without leaving the window.

### 5. The Ledger (GM Only)
Every transaction is logged. If a player adds 500gp, you will know exactly when and why.

## 🚀 Installation
1. Open Foundry VTT.
2. Go to **Add-on Modules** -> **Install Module**.
3. Paste this Manifest URL:
   `https://github.com/CtrlAltDefeatAM/gold-manager/releases/latest/download/module.json`
4. Click **Install**.
